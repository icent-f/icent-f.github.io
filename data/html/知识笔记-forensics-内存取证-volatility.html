Volatility

知识笔记 · Forensics / 内存取证2026-10-09

PART 1 概述

Volatility是一款用python编写的开源的内存取证工具

分为Volatility2与Volatility3 分别使用python2与python3编写

一般都是Volatility3 Windows7与Win7前的旧版考虑Volatility2

PART 2 使用对象

Volatility3作用的文件都是内存镜像文件

Volatility3 支持的内存镜像格式包括：

  • Raw（.raw/.mem/.dmp）
  • Windows 崩溃转储（.dmp）
  • VMware（.vmem）
  • VirtualBox（.sav）
  • Hyper-V（.bin）
  • EWF
  • LiME

PART 3 使用方法

如果下载的是python源码 就用python加参数运行

如果下载的是exe 直接加参数运行即可

vol2需要

vol.exe -f [image] --profile=[profile] [plugin]

而vol3已经不需要指定profile了

vol.exe -f [image] [plugin]

这里的 -f 就是指定分析的文件

[image] 就是内存镜像文件

[plugin] 就是插件

PART 3.1 参数

PART 3.1.1 全局参数

参数说明
-f, --file指定要分析的内存镜像文件
-o, --output-dir输出目录，用于存放 dump 出的文件
-r, --renderer输出格式：quick、pretty、json、csv 等
-q, --quiet抑制进度反馈，适合脚本或管道
--parallelism并行模式：processes、threads、off
-v, --verbose增加日志详细度，可叠加（如 -vvv）
-l, --log日志输出到指定文件
-p, --plugin-dirs额外插件目录（分号分隔）
-s, --symbol-dirs额外符号表目录（分号分隔）
-c, --config从 JSON 文件加载配置
-e, --extend单条配置项覆盖，格式 name=value
--save-config保存当前配置到 JSON 文件
--cache-path自定义缓存路径
--clear-cache清除短期缓存
--offline离线模式，不联网下载符号表

PART 3\.1\.2 插件专属参数

插件参数必须写在插件名之后 且不支持单字母简写

参数说明适用插件示例
--pid <PID>限定分析某个进程windows.dlllist, windows.handles, windows.vadinfo
--dump将结果转储为文件windows.memmap, windows.malfind
--yara-rules指定 YARA 规则yarascan
--strings-file指定字符串文件windows.strings

查看具体插件的参数可以用

vol <plugin_name> --help

例如 vol windows.pslist --help 会显示该插件支持的所有参数

PART 4.5 请给出用户yang88访问过文件“提现记录.xlsx”的北京时间？

[答案格式：2000-01-11 00:00:00]

需要访问文件的时间 可以查询NTFS 主文件表（MFT） 看他的元数据

用到的插件是 windows.mftsacn

注意 windows.mftsacn 是父插件 有三个子插件

需要标注使用的子插件才可以正常使用

  • windows.mftscan.MFTScan
    • 主插件 用于扫描内存中残留的 MFT 记录 并输出文件的元数据
  • windows.mftscan.ADS
    • 专门扫描 NTFS 的备用数据流（Alternate Data Streams） 用于检测隐藏数据
  • windows.mftscan.ResidentData
    • 提取存储在 MFT 记录内部的驻留数据（小文件的内容）
