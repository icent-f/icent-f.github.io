# BMP

[文章参考](https://www.cnblogs.com/wanghao-boke/p/11635179.html)

BMP(Bitmap) 位图 又叫DIB(Device-Independent Device) 设备无关图  
是windows系统中广泛使用的图片文件格式 可以不作任何变换地址保存图像像素域的数据

BMP分为五部分：
文件头 -> 标识这是个BMP文件
文件信息 -> 提供文件的大小和偏移量等信息
位图信息头 -> 提供图像数据的尺寸、位平面数、压缩方式、颜色索引等信息
调色板 -> 可选 使用索引表示图像
位图数据 -> 图像数据

主要写 **文件信息** 和 **位图信息头**

**文件信息**

| 内容       | 字节数 | 描述                               |
| ---------- | ------ | ---------------------------------- |
| 文件大小   | 4      | 文件的大小                         |
| 保留字1    | 2      | 大多数情况会被忽略 一般都是'00'    |
| 保留字2    | 2      | 同上                               |
| 起始偏移量 | 4      | 位图数据部分相对于文件的起始偏移量 |

通过偏移量 图像数据可以不紧随图像参数或调色板之后  
只要正确地设置偏移量 可以在调色板和数据部分之间填充任何内容

**位图信息头**

| 内容             | 字节数 | 描述                                     |
| ---------------- | ------ | ---------------------------------------- |
| 位图信息头的大小 | 4      | 通常是40或56                             |
| 图像宽度         | 4      | 图像宽度（像素）                         |
| 图像高度         | 4      | 图像高度（像素）                         |
| 无含义           | 2      | 现代bmp中恒为1                           |
| bpp              | 2      | 每个像素占用的位数                       |
| 压缩方式         | 4      | 可取 0、1、2、3 取3时大小为56 其余都为40 |
| 图像尺寸         | 4      | 图像的尺寸                               |
| 水平分辨率       | 4      | 水平分辨率                               |
| 垂直分辨率       | 4      | 垂直分辨率                               |
| 引用色彩数       | 4      | 引用色彩数                               |
| 关键色彩数       | 4      | 关键色彩数                               |

> 压缩方式
> 0 - RGB方式
> 1 - 8bpp的run-length-encoding方式
> 2 - 4bpp的run-length-encoding方式
> 3 - bit-fields方式
