# 明文攻击

其实一般都会用 **bkcrack** 这个工具  
如果有完整的文件 **ARCHPR** 也可以做

ZipCrypto的加密方式是可以明文攻击的 AES就基本打不通了

原理其实可以这么理解

```
厨子端上来一份西红柿炒鸡蛋(压缩文件)
原料是西红柿和鸡蛋(压缩包里的文件 就当成是 西红柿.txt 和 鸡蛋.txt 吧)

我手上没有鸡蛋(压缩包里有 但你目前没有的文件 也就是密文)
只有和厨子一个菜市场买的西红柿(压缩包里有 你也有的文件 也就是明文)

但我晓得厨子的炒西红柿是怎么炒的(压缩方式)
因为鸡蛋和西红柿是一块炒的(鸡蛋.txt 和 西红柿.txt 是一起压缩的 密码、压缩方式是一致的)

所以我能用炒好的西红柿(压缩后的西红柿.txt)
推理出鸡蛋的烹饪方式 进而推理出西红柿炒鸡蛋的烹饪方式
(通过明文 推出密文的加密方式 得到3个内部状态密钥)

(3个内部状态密钥的作用基本等效于密码 已经能解压缩包了)
(不过如果用ARCHPR 会顺带把密码也推出来给你)

(这里就不接着类比了 有了密码接下来要干什么就都知道了)
```

拿例题来说 我们有一个和压缩包里一样的jpg文件 也是就“西红柿”  
文件名还告诉我们是7zip压缩的 也就是“烹饪方法”  
那7zip压缩完的jpg文件就可以作为明文文件 也就是“和厨子一个炒法做的炒西红柿”  
然后交给工具 就可以爆出口令了

> 值得一提的是 不是所有明文攻击都这么大方能给一个文件  
> 只靠几个字节解明文加密也是不少见的
