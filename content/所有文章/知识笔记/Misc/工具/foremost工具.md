# foremost

foremost 是一个基于文件头和文件尾特征的数据雕复（data carving）工具  
常用于从磁盘镜像、内存 dump、网络流量抓包 甚至单个文件中快速分离和恢复隐藏/删除的文件

| 选项          | 说明                                                    |
| ------------- | ------------------------------------------------------- |
| `-i 输入文件` | 指定输入文件                                            |
| `-o 输出目录` | 指定输出目录（必须为空或不存在）                        |
| `-t type`     | 指定要恢复的文件类型 多个用逗号分隔 如 `-t jpg,pdf,doc` |
| `-a`          | 不检测文件系统边界 扫描整个输入                         |
| `-b size`     | 设置块大小（默认 512 字节）                             |
| `-v`          | 详细模式，显示更多过程信息                              |
| `-q`          | 快速模式，只搜索文件头，不校验文件尾                    |
| `-c file`     | 使用自定义配置文件（自定义签名）                        |
| `-s num`      | 跳过输入文件开头的指定扇区数（优化扫描）                |
