# binwalk

一款用于分析、识别和提取嵌入在其他文件中的隐藏文件或数据的固件分析工具

这里列一下binwalk的使用方法 分成 **分析 提取 其他**

**分析**

用于扫描和获取信息 不会修改文件本体

| 命令             | 功能                                                                                | 示例                           |
| ---------------- | ----------------------------------------------------------------------------------- | ------------------------------ |
| `binwalk 文件名` | **默认扫描** 分析并列出文件中检测到的所有文件签名和特征                             | `binwalk 文件名`               |
| `-E`             | **熵值分析** 生成熵值曲线图，判断数据是加密/压缩（高熵）还是明文/结构化数据（低熵） | `binwalk -E 文件名`            |
| `-R "字符串"`    | **原始字符串搜索** 在文件中直接搜索给定的 ASCII 或 Unicode 字符串                   | `binwalk -R "搜索字符" 文件名` |
| `-B`             | **跳过签名扫描** 不检测文件类型，只做后续指定的分析（如 熵 字符串）                 | `binwalk -B -E 文件名`         |
| `-Y`             | **签名扫描** 不提取文件 只进行核心的签名匹配扫描                                    |
| `-A`             | **搜索CPU指令** 用于识别固件中的特定架构指令（如ARM、MIPS） 常用于路由器逆向        | `binwalk -A 文件名`            |
| `-I`             | **显示签名信息** 列出所有内置支持的文件魔数和特征 并可以配合过滤                    | `binwalk -I \| grep "zip"`     |
| `-q`             | **安静模式**，抑制非必要的输出，适合脚本调用                                        | `binwalk -q -e 文件名`         |

**提取**

用于将隐藏或嵌入的文件分离出来

| 命令                    | 功能                                                                                   | 示例                              |
| ----------------------- | -------------------------------------------------------------------------------------- | --------------------------------- |
| `-e`                    | **自动提取** 根据识别出的文件签名 自动将所有已知类型的文件提取出来                     | `binwalk -e 文件名`               |
| `--run-as=root`         | **以root身份运行** 提取某些文件提示权限不足时使用                                      | `binwalk -e --run-as=root 文件名` |
| `-D "类型:描述:扩展名"` | **自定义提取规则** 将检测到指定特征的数据段 全部按该类型提取                           | `binwalk -D "png:png:png" 文件名` |
| `-D ".*"`               | **暴力全提取** 将文件中**所有**识别到的数据块 无论类型全部提取                         | `binwalk -D=".*" 文件名`          |
| `-M`                    | **递归扫描** 将提取出的文件再次进行 `binwalk` 分析 常与 `-e` 组合成 `-Me` 用于递归提取 | `binwalk -Me 文件名`              |
| `-d 深度`               | **限制递归深度** 配合 `-Me` 用于限制解包的层数 防止无限套娃                            | `binwalk -Me -d 3 文件名`         |
| `-dd`                   | **直接提取** 不依赖文件签名 按文件在数据流中的物理位置进行连续提取                     | `binwalk -dd=".*" 文件名`         |

**其他**

| 命令         | 功能                                                                      |
| ------------ | ------------------------------------------------------------------------- |
| `binwalk -X` | **十六进制转储** 将扫描结果显示为十六进制和ASCII对照 方便手动分析数据结构 |
| `binwalk -W` | **Zip暴力破解** 内置简单模块 可通过明文攻击尝试破解传统加密的Zip文件      |
| `binwalk -u` | **更新魔数库** 更新内置的文件特征识别库                                   |
