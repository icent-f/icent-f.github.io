# pngcheck的使用方法

| 选项         | 功能说明                                                                  |
| :----------- | :------------------------------------------------------------------------ |
| **(无选项)** | **检查文件**，打印文件名、尺寸、色深等概要信息。                          |
| `-v`         | **详细模式**，打印大部分数据块（chunk）的信息。                           |
| `-vv`        | **超详细模式**，在 `-v` 的基础上进一步解码并打印行过滤器信息。            |
| `-q`         | **安静模式**，只在发现错误时输出信息。                                    |
| `-c`         | **彩色输出**，为不同信息类型添加颜色，便于阅读（需ANSI终端支持）。        |
| `-t`         | **打印文本块**，显示 tEXt 数据块的内容，常用于查看图片的元数据。          |
| `-p`         | **打印调色板**，显示 PLTE、tRNS 等与颜色相关的数据块内容。                |
| `-7`         | 结合 `-t` 使用，将 tEXt 中 ASCII >= 128 的字符转义显示，用于 7-bit 终端。 |
| `-s`         | **搜索模式**，在指定的文件中搜索 PNG 图像。                               |
| `-x`         | **提取模式**，在指定文件中搜索 PNG 图像并将其提取出来。                   |
